Skills demonstrated

  • Enumerated directories and fingerprinted the application stack.

Findings Summary

Severities and remediations below were assigned retrospectively from the documented evidence using standard OWASP/CVSS-style judgment (Critical / High / Medium / Low). They were not part of the original lab write-up.

This assessment documents 10 distinct observations (the original objective said "eight unique prioritized findings"; the table below is the full enumerated set from the Steps, without consolidating duplicates).

IDIssueOWASP categorySeverityFixEvidence
CR-01Broken object-level authorization: changing user ID 8 to 3 returns another user's dataOWASP API1:2023 BOLAHighEnforce object-level authorization on every request; bind resource IDs to the authenticated subject and return 403/404 for cross-user access.Ref 3
CR-02Unsigned JWT (alg: none, signature removed) accepted by the APIOWASP API2:2023 Broken AuthenticationCriticalReject alg: none and unsigned tokens; whitelist allowed algorithms (e.g. RS256/HS256); verify signatures with a server-side key; rotate keys.Refs 4-7
CR-03No account lockout or effective throttling on repeated invalid loginsOWASP API4:2023 Unrestricted Resource ConsumptionMediumAdd progressive rate limiting, account lockout or CAPTCHA after repeated failures, and monitor for credential-stuffing patterns.Refs 8-9
CR-04Exposed MailHog message API (/api/v2/messages) reveals mailbox data, including a one-time passwordOWASP API8:2023 Security MisconfigurationHighDo not expose mail-catcher APIs outside local/dev; require auth and network restriction; never return OTPs via unauthenticated endpoints.Refs 10, 20
CR-05SQL payload accepted and reflected in community post content (weak input validation)OWASP A03:2021 InjectionMediumValidate and encode user content; use parameterized queries server-side; apply output encoding to prevent stored injection/XSS.Refs 11-12
CR-06NoSQL-style $regex payload on coupon validation returns a valid couponOWASP A03:2021 InjectionHighTreat coupon input as a scalar string; reject operator objects ($regex, $gt, etc.); use allow-listed coupon lookup.Refs 13-14
CR-07Verbose Spring validation error discloses backend implementation detailsOWASP API8:2023 Security MisconfigurationLowReturn generic client errors in production; log details server-side only; disable stack traces and framework internals on public APIs.Ref 15
CR-08/.env on port 8888 exposes environment variables and database configurationOWASP API8:2023 Security MisconfigurationCriticalBlock access to .env and config paths; keep secrets in a vault or environment not served by the web root; rotate any exposed credentials.Ref 16
CR-09Community posts endpoint exposes other users' author detailsOWASP API3:2023 Broken Object Property Level AuthorizationMediumApply response filtering / BOPLA controls so clients only receive fields and records they are authorized to see.Ref 17
CR-10Shop orders are enumerable: /orders/1 and /orders/5 return other customers' and admin order/card metadataOWASP API1:2023 BOLACriticalAuthorize order access by ownership/role; use non-guessable IDs; never return full payment-card metadata to unauthorized callers.Refs 18-19
