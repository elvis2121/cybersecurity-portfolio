VulnBank Web, API, and Mobile Security Assessment

Assessed a banking training environment across web, API, and Android surfaces, documenting fifteen security issues with ordered proof and remediation guidance.

Findings Summary

Severities and remediations below were assigned retrospectively from the documented evidence using standard OWASP/CVSS-style judgment (Critical / High / Medium / Low). They were not part of the original lab write-up.

This assessment documents 15 distinct observations. The original objective cited fourteen issues; the table enumerates every validated item from the Steps (including the debug-certificate finding) without dropping any.

IDIssueOWASP categorySeverityFixEvidence
VB-01Vulnerable client library: DOMPurify 2.3.3OWASP A06:2021 Vulnerable and Outdated ComponentsMediumUpgrade DOMPurify to a patched release; track JS dependencies with SCA and block known-vulnerable versions in CI.Ref 3
VB-02Admin login brute-forced with Burp IntruderOWASP A07:2021 Identification and Authentication FailuresHighEnforce a strong password policy, rate limiting, lockout/MFA, and monitoring for repeated failures (see also Ref 7).Refs 6-7
VB-03SQL injection login bypass to the admin portalOWASP A03:2021 InjectionCriticalUse parameterized queries for authentication; never concatenate credentials into SQL; add WAF/input validation as defence in depth.Ref 8
VB-04/api/v3/forgot-password can be downgraded to v1, exposing the email OTPOWASP API9:2023 Improper Inventory ManagementHighRetire or harden old API versions; block version downgrade; never return OTPs in API responses.Refs 9-10
VB-05No rate limiting on the login endpointOWASP API4:2023 Unrestricted Resource ConsumptionHighApply per-IP and per-account rate limits, backoff, and anomaly detection on authentication endpoints.Refs 11-12
VB-06/register returns excessive debug and server informationOWASP API8:2023 Security MisconfigurationMediumReturn generic errors to clients; disable debug banners and server version leakage in production.Ref 13
VB-07API documentation exposed at /api/docs without authenticationOWASP API9:2023 Improper Inventory ManagementMediumRestrict Swagger/OpenAPI UIs to authenticated admin networks or remove them from production.Ref 14
VB-08JWT algorithm downgraded from HS256 to none with the signature removedOWASP API2:2023 Broken AuthenticationCriticalWhitelist algorithms; reject none; verify signatures with server-managed keys; prefer asymmetric JWT where feasible.Ref 15

VB-11Debug endpoint /debug/users declared in the manifestOWASP Mobile M8:2024 Security MisconfigurationHighRemove debug components from release builds; gate with build flavours; require auth if retained in non-prod.Ref 19
VB-12Sensitive data stored in plaintext Shared PreferencesOWASP Mobile M9:2024 Insecure Data StorageHighUse EncryptedSharedPreferences / Keystore; store tokens not passwords; clear data on logout.Ref 20
